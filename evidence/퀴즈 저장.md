# 퀴즈 저장

`cli` 모듈에서 퀴즈를 새로 만드는 함수를 만들고 `quizgame` 모듈의 `QuizGameManager` 의 `.quiz_add` 메소드를 구현하여 저장하게 했습니다.

`cli` 퀴즈 만들기
``` python
def add_menu(manager: QuizGameManager):
    '''퀴즈 추가'''
    try:
        new_quiz = Quiz(input("질문: "), [], None, "")
        for i in range(1, 5, 1):
            new_quiz.choices.append(input(f"보기 {i}: "))
        new_quiz.hint = input("힌트: ")
        new_quiz.answer = input("정답: ")
    except ValueError:
        print("퀴즈 추가 취소")
        return list_menu(manager)
    except (KeyboardInterrupt, EOFError):
        manager.save()
        print("게임을 종료합니다.\n")
    
    manager.quiz_add(new_quiz)
    return list_menu(manager)
```

`QuizGameManager` `.quiz_add` 메소드
``` python
    def save(self):
        '''상태 정보 파일로 저장'''
        self.state_data["quizzes"] = [asdict(quiz) for quiz in self.quizzes]
        if self.scores is not None:
            for score in self.scores:
                score.time = score.time.isoformat()
            self.state_data["scores"] = [asdict(score) for score in self.scores]
        if isinstance(self.highest, Score):
            self.highest.time = self.highest.time.isoformat()
            self.state_data["highest"] = asdict(self.highest)
        self.state_data["highest"] = self.highest
        save_json(self.root_path, self.state_data)
```
