# 메뉴
사용자 인터페이스를 `cli` 모듈에 모두 구현했고, `quizgame`의 `class`들을 활용하였습니다.  

`run()` 는 `main_menu()` 의 단순한 랩퍼함수이며 굳이 만들어둔 이유는  
매니저 객체를 만들어 메뉴/화면들에 인자로 전달해 상태를 관리하게 했기 때문입니다.  

[cli 소스 코드](src/cli.py)

``` python
PATH = Path(__file__).parent / 'state.json'

def run():
    '''시작'''
    manager = QuizGameManager(PATH)
    main_menu(manager)
```
