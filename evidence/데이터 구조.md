## 퀴즈 및 점수 class 구조

공통 특징
- 퀴즈, 점수 둘 다 `dataclass`로 만들었습니다.  
- 둘 다 `from_dict` 로 딕셔너리를 읽어 만들 수 있게 했습니다.  
- `dataclass`로 만들었기 떄문에 `dataclass.asdict()`를 사용해 간단하게 딕셔너리로 변환해 저장할 수 있습니다.
하지만 `Score` 점수 클래스는 내부에 `datetime`시간도 같이 저장하기 떄문에 점수 인스턴스 딕셔너리 변환 전에 내부 time 필드 먼저 바꿔줘야 합니다.
- 퀴즈, 점수 둘 다 `to_string` 메소드로 문자열 형식으로 가져올 수 있습니다.

개별 특징  

- 퀴즈는 `is_correct()` 메소드로 정답이 맞는지 확인할 수 있습니다.
- 점수는 '__lt__', '__eq__' 매직 메서드로 비교 연산이 가능합니다.  

- **퀴즈 필드**:
  - 질문: str
  - 보기 n개: list[str]
  - 정답: str
  - 힌트: str

- **점수 필드**:
  - 점수: float
  - 문제 수: int
  - 맞춘 수: int
  - 힌트를 쓴 횟수: int
  - 푼 시간: datetime


``` python
@dataclass
class Quiz: # 퀴즈
    question: str
    choices: list[str]
    answer: str
    hint: str

    @classmethod
    def from_dict(cls, quiz):
        '''딕셔너리를 퀴즈로 읽기'''
        return cls(**quiz)

    def is_correct(self, user_answer: str | int):
        '''점답 확인'''
        if isinstance(user_answer, int):
            if user_answer > len(self.choices):
                return False
            return self.answer == self.choices[user_answer]
        return self.answer == user_answer

    def to_string(self, index, get_hint: bool, get_answer: bool):
        '''퀴즈 정보를 문자열로 리턴'''
        result = [f"{index}) {self.question}"]
        if get_hint is True:
            result.append(f"(힌트: {self.hint})")
        for j, choice in enumerate(self.choices, start=1):
            result.append(f"    {j}. {choice}")
        if get_answer is True:
            result.append(f"    정답: {self.answer}")
        return "\n".join(result)

@dataclass
class Score:    # 점수
    score: float
    number: int
    correct: int
    hint: int
    time: datetime

    @classmethod
    def from_dict(cls, score_dict: dict):
        '''딕셔너리를 Score로 읽기'''
        if isinstance(score_dict.get("time"), str):
            score_dict["time"] = datetime.fromisoformat(score_dict["time"])
        return cls(**score_dict)

    @property
    def to_string(self):
        '''점수 정보를 문자열로 리턴'''
        result = [f"점수: {self.score}점 {self.correct}/{self.number} | 힌트: {self.hint}/{self.number}"]
        result.append(f"날짜: {self.time}")
        return "\n".join(result)

    # 최고 점수 비교를 위해 넣은 equal, less than 던더 메소드
    def __eq__(self, other: Score):
        if not isinstance(other, Score):
            return NotImplemented
        return self.score == other.score
    
    def __lt__(self, other: Score):
        if not isinstance(other, Score):
            return NotImplemented
        return self.score < other.score

```
