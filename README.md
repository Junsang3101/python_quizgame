# python_quizgame

## 0. 프로젝트 개요

본 프로젝트는 '코디세이 입학 연수 미션 1-2:파이썬 배우기'로  
파이썬으로 퀴즈게임을 만드는 것입니다.

**목적**: 프로그래밍 배우기의 일환으로 Python 과 Git 을 활용하여 프로그램을 만들기 기록하고 내가 만든 프로그램이 왜 이렇게 동작하는지 설명할 수 있게 되는 것입니다.
